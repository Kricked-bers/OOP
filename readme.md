# Проект банковского приложения

## Описание

Проект направлен на изучение ООП, классов и работы с ними

## Тело проекта

1. Представленные классы

```
BaseClass - Абстрактный класс родитель для класса Product
MixinRepr - Класс Миксин для вывода информации о создаваемом классе
Product - Класс продукта, необходимо задать: название, описание, цену и колличество
Category - Класс категории, необходимо задать: название, описание, список продуктов
Smartphone - дочерний класс Product
LawnGrass - дочерний класс Product
```
